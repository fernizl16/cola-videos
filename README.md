# Cola de vídeos

App para el móvil que muestra el siguiente vídeo a publicar de **Curiosa** y **MitoVerso**, con su portada y su pie de foto, y que marca cada vídeo como publicado.

Ábrela en el móvil: **https://fernizl16.github.io/cola-videos/** y añádela a la pantalla de inicio.

Los vídeos están en los repos privados `videos-cuenta1` (Curiosa) y `videos-cuenta2` (MitoVerso).
